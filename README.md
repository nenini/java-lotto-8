# java-lotto-precourse

# 1) 개요

- **목표**: 사용자가 입력한 구입 금액만큼 로또를 발행하고, **당첨 번호 + 보너스 번호**와 비교해 **당첨 통계와 총 수익률**을 출력
- **번호 규칙**: 1~45 사이의 **중복 없는 6개**가 1장, 표시 시 **오름차순 정렬**
- **추첨 규칙**: 당첨 번호(6개, 중복 없음) + **보너스 번호 1개(당첨 번호와 중복 금지)**
- **등수 규칙(보상)**

  1등: 6개 / 2,000,000,000원

  2등: 5개 + 보너스 / 30,000,000원

  3등: 5개 / 1,500,000원

  4등: 4개 / 50,000원

  5등: 3개 / 5,000원

- **예외 정책**: 잘못된 입력 시 `IllegalArgumentException` 발생 → `"[ERROR] ..."` 출력 후 **해당 입력부터 재입력**
- **입력/랜덤 API(필수)**:

  `camp.nextstep.edu.missionutils.Console.readLine()` / `Randoms.pickUniqueNumbersInRange(1, 45, 6)`

- **실행 진입점**: `Application.main(String[] args)`

---

# 2) 입·출력 명세

## 입력

1. **구입 금액**(정수, 1,000원 단위, 1,000으로 나누어떨어짐)

    ```
    14000
    ```

2. **당첨 번호 6개**(쉼표`,` 구분, 공백 허용)

    ```
    1,2,3,4,5,6
    ```

3. **보너스 번호 1개**(정수 1~45, 당첨 번호와 **중복 금지**)

    ```
    7
    ```


## 출력

1. **발행 수량 및 각 로또 번호(오름차순)**

    ```
    8개를 구매했습니다.
    [1, 8, 11, 31, 41, 42]
    [2, 13, 22, 32, 38, 45]
    ...
    ```

2. **당첨 통계(고정 포맷)**

    ```
    당첨 통계
    ---
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
    총 수익률은 62.5%입니다.
    ```

3. **에러 출력**
    - 항상 `"[ERROR]"`로 시작
    - 예: `[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.`

# 3) 기능 목록(체크리스트)
- [ ]  **F1. 입출력 프롬프트/형식 출력**
    - 구입 금액 → 당첨 번호 → 보너스 번호 입력 순서 유지
    - 발행 수량/로또 번호, 당첨 통계/수익률 출력 포맷 **예시와 동일**
- [ ]  **F2. 구입 금액 파싱/검증**
    - 공백 트림 후 정수 파싱
    - **1,000 단위 & 1,000 이상** 확인 (예: `0`, `-1000`, `1500` → 오류)
    - 잘못된 입력은 `IllegalArgumentException` 발생, 에러 메시지 출력 후 **재입력**
- [ ]  **F3. 로또 발행**
    - 장수 = `구입 금액 / 1000`
    - 각 장: `Randoms.pickUniqueNumbersInRange(1, 45, 6)` 사용
    - 내부 저장 시 오름차순 정렬
    - **~~중복 방지**는 Randoms 보장 + 검증~~
- [ ]  **F4. 당첨 번호/보너스 번호 파싱/검증**
    - 당첨 번호: 쉼표 기준 분리 → 트림 → 정수 → **6개** & **1~45** & **중복 없음**
    - 보너스 번호: 정수 1~45, **당첨 번호와 중복 금지**
    - 형식 오류·범위 오류·중복 시 `IllegalArgumentException` 및 **재입력**
- [ ]  **F5. 당첨 판정**
    - 각 로또와 당첨 번호 **겹치는 개수** 계산
    - `Rank` **Enum**으로 등수 매핑
        - 6 → `FIRST`
        - 5 + 보너스 포함 → `SECOND`
        - 5 → `THIRD`
        - 4 → `FOURTH`
        - 3 → `FIFTH`
        - 그 외 → 미당첨(집계 제외)
    - 등수별 **개수 카운트**
- [ ]  **F6. 수익률 계산**
    - 총 당첨 금액 = 등수별 금액 × 개수 합
    - 수익률(%) = `총 당첨 금액 / 구입 금액 * 100`
    - **소수점 둘째 자리에서 반올림(한 자리까지 표시)**
        - 예: `100.0%`, `51.5%`, `1,000,000.0%`

# 4) 예외/엣지 케이스

- 구입 금액: 
  - `" 8000 "` → OK 
  - `"800"`·`"0"`·`"-1000"`·`"a1000"` → **에러**
- 당첨 번호: 
  - `"1, 2, 3, 4, 5, 6"` OK 
  - `"1,2,3,4,5"`(개수 부족)·`"0"`(범위)·`"1,1,2,3,4,5"`(중복) → **에러**
- 보너스 번호: 당첨 번호와 **중복 시 에러**
- 로또 번호 출력: 항상 **오름차순**
- 수익률 포맷: 항상 소수 **한 자리**까지(둘째 자리 반올림), **%** 포함
